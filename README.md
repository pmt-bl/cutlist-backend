# Cutlist — Backend

Backend for Cutlist, a platform for video editing / digital art freelancers:
a public directory where freelancers can be found, plus a private dashboard
for tracking clients and invoices.

Built as a learning project to get hands-on with backend fundamentals —
routing, authentication, authorization, and relational data modeling.

## Stack

Node.js · Express · TypeScript · PostgreSQL · Prisma
